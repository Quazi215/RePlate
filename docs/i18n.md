# Hiraku languages

Hiraku stores the chosen application locale (`en`, `es`, `zh-Hant`, `ar`, `bn`, `fr`, `ht`, `ko`, `pl`, `ru`, or `ur`) locally in the browser. Invalid saved values fall back to English. The interface uses static dictionaries and English fallback; the non-English text is a draft and requires fluent-speaker and SNAP terminology review before it can be called reviewed or certified. The language switch does not change screening answers or income rules.

Shosai receives the application locale in each guidance and recording request. The app has no document upload, OCR, or document explanation feature; the screening page only offers a document preparation checklist. Quoted document text in a question remains untrusted. Official links are resolved from reviewed source IDs.

The configured speech path uses `eleven_flash_v2_5` for spoken answers and `scribe_v2_realtime` for live transcription, followed by Gemini guidance and the same speech path. Voice is enabled only for English, Spanish, Arabic, French, Korean, Polish, and Russian. Bengali, Haitian Creole, Urdu, and Traditional Chinese stay text-only; Mandarin support does not establish a Traditional Chinese spoken variety. No locale silently falls back to English audio. The configured voice may have an accent in supported non-English languages and has not been audited for pronunciation.

Provider support was checked against [ElevenLabs' model language lists](https://elevenlabs.io/docs/overview/models), [Scribe v2 language list](https://elevenlabs.io/docs/overview/capabilities/speech-to-text/), and [realtime API language-code contract](https://elevenlabs.io/docs/api-reference/speech-to-text/v-1-speech-to-text-realtime) on October 11, 2026. Provider availability can change. The local presenter-operated demo and provider account permissions remain as described in the repository README.
